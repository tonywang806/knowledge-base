# AI 知识库系统

基于多 Agent 协作的 AI 技术知识库——自动采集、智能分析、定时推送

## 架构概览

```
┌─────────────────────────────────────────────────────────────────────┐

│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐ │
│  │  采集 Agent │→│  分析 Agent │→│  整理 Agent │→│  分发 Agent │ │
│  └─────────────┘  └─────────────┘  └─────────────┘  └─────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│                        Pipeline 层                                   │
│  ┌────────┐  ┌─────────┐  ┌────────┐  ┌─────────┐  ┌────────────┐ │
│  │ Collect │→│ Analyze │→│ Organize│→│ Revise   │→│   Publish  │ │
│  └────────┘  └─────────┘  └────────┘  └─────────┘  └────────────┘ │

```

## 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/yourusername/ai-knowledge-base.git
cd ai-knowledge-base

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，填入 API Key：
# - DEEPSEEK_API_KEY=sk-xxxx
# - TELEGRAM_BOT_TOKEN=xxx
# - FEISHU_WEBHOOK=xxx

# 3. 启动服务
docker compose up -d
```

## 目录结构

|------|------|------|
| `bot/` | Telegram/飞书机器人交互模块 | v4.0+ |

## 技术栈

- **AI 编排**: OpenCode + 国产大模型 (DeepSeek / Qwen / GLM / Kimi)
- **工作流**: LangGraph
- **部署**: Docker + docker-compose
- **消息分发**: Telegram Bot API / 飞书 Webhook
- **存储**: JSON 文件 (knowledge/articles/)
- **语言**: Python 3.12

## 版本历史

| 版本 | 阶段 | 核心能力 |
|------|------|----------|
| V1 | 原始采集期 | 手动爬取 GitHub Trending，简单 JSON 存储 |
| V2 | 流水线化 | 引入 Pipeline 调度，支持每日自动采集 |
| V3 | Agent 化 | 引入 LLM 分析，LangGraph 工作流，智能打标评分 |
| V4 | 多渠道分发 | Telegram/飞书机器人，订阅推送，意图识别交互 |
